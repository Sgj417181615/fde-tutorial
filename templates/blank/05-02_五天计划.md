# A05-02 五天计划

> 产物路径：`05_五天验证/05-02_五天计划.md` ｜ 所属阶段：05_五天验证 ｜ 阶段门：G5

## 用途

把五天拆成每天可展示的增量，确保最后一天不是第一次跑通。计划要同时安排业务方时间、数据准备、方案设计、Demo 排练与阶段门。

## 何时用

- D1 开始前，与业务方一起排定；
- 每天晨会确认当天目标；
- 发现某天没有可展示产出时，立即调整；
- D5 复盘时对照计划与实际。

## 填写说明

1. 一天一行，日期写 D1 至 D5 或具体日期，全表统一。
2. 上午、下午写具体活动，动词开头，不写“继续推进”。
3. 参与人写真实角色；关键审批人是否到场要单独确认。
4. 产出写 artifact 编号与文件名，不写“相关文档”。
5. 展示时点固定；每天至少一次向业务方展示可操作增量。
6. 风险写最可能让当天失败的一件事，并给出应对。
7. 为已知冲突、审批和数据问题预留时间，不把计划排满。

## 质量门自检（G5）

- [ ] 每天都有可展示的增量，而不是最后一天才演示。
- [ ] 上午、下午的安排能落到具体产物。
- [ ] 参与人写明真实角色，关键审批人已预约。
- [ ] 产出使用 artifact 编号与文件名。
- [ ] 展示时点固定，且业务方能到场。
- [ ] 每天至少列一条风险与应对。
- [ ] 计划为已知冲突和审批留出了处理时间。
