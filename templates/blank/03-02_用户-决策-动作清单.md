# A03-02 用户-决策-动作清单

## 用途 / 何时用

在 As-is 决策流之后使用。它把流程拆成一个个决策点，回答“谁在什么时点、根据什么输入、做什么决定，决定后触发什么动作”。一行必须是一个决策，不是一段流程。

## 填写说明

- 一个决策一行；同一角色在不同时点的决策分开写。
- “角色”写到做决定的人，不写部门或系统。
- “场景”写这个决策发生的业务情境。
- “决策”写一个可陈述的选择，不写“支持某某管理”。
- “时点”写到日期、事件或相对时间，例如“每月 25 日前”。
- “输入”写做决定实际要看的信息。
- “动作”写决定之后人或在系统里做什么；写不出动作就说明这不是决策。
- “系统”写承载动作的系统、表格或渠道；“频率”写月度、每周、每次等。
- “证据ID”引用 A02-04 或 A02-01；推测的决策标【待确认】。

## 质量门自检（G3）

- [ ] 每一行只包含一个决策，没有把流程步骤当决策。
- [ ] 每个决策都能回答“谁、何时、决定什么”。
- [ ] 每个决策之后都有明确动作，写不出动作的行已删除。
- [ ] 时点具体到日期、事件或相对时间。
- [ ] 输入是决策实际依赖的信息，不是泛泛的数据清单。
- [ ] 系统与频率已填，能判断动作发生在哪里、多久一次。
- [ ] 关键决策都有证据ID，推测项已标【待确认】。
- [ ] 清单中能指出本轮切片要支撑的最终决策。
