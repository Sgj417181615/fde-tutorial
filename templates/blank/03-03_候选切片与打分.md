# A03-03 候选切片与打分

## 用途 / 何时用

在现状和决策清单清楚之后使用。列出至少三个候选切片，用同一组维度比较，最后选出一个五天内能验证、又真实值得做的切片。打分用于暴露分歧，不是追求精确。

## 填写说明

- 一个候选切片一行；至少三个，包含“暂缓”和“不做”的选项。
- “切片”用一句话说明范围，不写项目名或系统名。
- “决策”写这个切片要支撑的最终决策；没有决策的切片要说明原因。
- “价值”“可行性”“证据强度”“风险”统一用 1–3 分，并在括号内写一句依据。
- 风险分越高表示出错代价或依赖越大；不要把风险直接加进总分。
- “总分”必须注明计算口径，例如“价值 + 可行性 + 证据强度”，或团队约定的加权方式。
- “结论”只写选中、第二轮、暂缓、不做；选中项要能对应后续 one-pager。

## 质量门自检（G3）

- [ ] 至少列出三个候选切片，包含不做或暂缓的选项。
- [ ] 每个切片都能对应一个明确的最终决策。
- [ ] 四个评分维度使用同一口径，并写了简短依据。
- [ ] 风险分的方向已说明，没有与总分混淆。
- [ ] 总分写明了计算口径，可被他人复核。
- [ ] 结论使用统一取值，选中项只有一个。
- [ ] 选中切片能在五天内由真实用户走完一次决策闭环。
- [ ] 未选中的切片写清了下一轮或暂缓的理由。
