# A02-05 待确认与问题清单

## 用途 / 何时用

在现场记录和证据整理过程中持续维护。它收集还不能下结论的问题，写明影响、当前假设、验证方式和责任人，避免把疑问留在个人记忆里。

## 填写说明

- 一个问题一行，按对决策的影响排序。
- “影响”写不解决会妨碍哪个判断、产物或阶段门。
- “当前假设”写团队当前的临时答案，并标明这是假设。
- “验证方式”写找谁、看什么文件、做什么观察或测什么数据。
- “负责人”写到具体人；“截止日期”写到日。
- “状态”只写待验证、验证中、已确认、已否决、已转待办。
- 已确认的结论转写到 A02-04，不要只在本表留一句“已解决”。

## 质量门自检（G2）

- [ ] 每条问题都写了不解决会妨碍什么。
- [ ] 当前假设明确标为假设，没有当成结论。
- [ ] 验证方式具体到人、文件、观察或数据。
- [ ] 每条都有负责人和截止日期。
- [ ] 状态使用统一取值，没有自造标签。
- [ ] 已确认的问题已转写为证据台账条目。
- [ ] 影响阶段门判断的问题已排在最前面。
