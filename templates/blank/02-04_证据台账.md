# A02-04 证据台账

## 用途 / 何时用

在每次访谈、观察或拿到文件后立即登记。它把“谁在什么状态下说了什么”变成可引用、可降级的证据，后续 one-pager、切片和阶段门结论都必须能回到这里。

## 填写说明

- 一条证据一行，分配唯一“证据ID”，例如 E-01。
- “原文或观察”优先保留原话或可复述的观察，不用结论替代。
- “来源”写说话人、观察编号、文件名或系统，精确到可回查。
- “访谈状态”只写原文/观察、业务确认、工作假设、待验证四类之一。
- “权威性”只写官方、第三方、实践、推断、待确认五类之一。
- “影响决策”写这条证据支撑或推翻哪个判断，不写“参考”。
- “待确认项”写还不能下结论的部分；“负责人”和“截止日期”必须有着落。
- 状态变化时更新本行，并在备注中保留变更原因。

## 质量门自检（G2）

- [ ] 每条关键结论都能对应至少一个证据ID。
- [ ] 原文与推断分开记录，没有把假设写成事实。
- [ ] 每条证据都同时标注了访谈状态和权威性。
- [ ] 来源精确到可回查的人、文件或观察编号。
- [ ] “影响决策”写的是具体判断，不是笼统的“参考”。
- [ ] 每个待确认项都有负责人和截止日期。
- [ ] 待验证或待确认的证据没有进入最终结论。
- [ ] 状态变更保留了变更原因。
