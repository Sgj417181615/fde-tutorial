# A03-05 use-case one-pager

## 用途 / 何时用

在切片选定之后、进入方案设计之前使用。用一页纸锁定一个用户、一个最终决策、一条端到端路径和明确的不做范围，作为 D1 工作底稿和后续 FR 的共同基线。

## 填写说明

- 全页只承诺一个最终决策；相邻决策写进“不做什么”或后续轮次。
- “用户”写具体角色和场景，写清谁操作、谁确认、谁审批。
- “决策”用一个可陈述的选择，不写功能清单。
- “输入”写做决定实际要看的数据、规则和材料。
- “动作”写决定之后在界面上或流程中发生什么，写清是否写回。
- “价值”写可观察变化；有基线就引用 A01-04，没有就标“待测量”，并同时写测量方式、数据来源、校准日期和负责人。
- “不做什么”至少三条，包含相邻切片和自动决策边界。
- “成功标准”必须能在五天内由真实用户验证。
- “相关方”写审批、操作、需求确认和数据权限角色；“现状”写今天的实际做法。

## 字段

### 标题

（用“对象 + 决策”命名，不写系统名）

### 用户

（主操作者、需求提出者、确认者、审批者；写到角色和场景）

### 决策

（本轮唯一要支撑的最终决策）

### 输入

（决策实际依赖的需求、额度、可用性、资质、规则等）

### 动作

（决定后发生什么：调整、校验、保存、写回、提交、审批）

### 价值

（用户与业务的可观察变化；基线来源；无基线时写“待测量”+ 测量方式、数据来源、校准日期、负责人）

### 不做什么

（相邻切片、自动决策边界、无关系统，至少三条）

### 成功标准

（五天内可验证的条件，写清观察方式）

### 相关方

（审批、操作、需求确认、数据与权限角色）

### 现状

（今天的工具、版本、协调方式和主要卡点）

## 质量门自检（G3）

- [ ] 全页只承诺一个最终决策。
- [ ] 用户写到具体角色，且区分操作者、确认者和审批者。
- [ ] 输入与决策直接相关，没有堆无关数据。
- [ ] 动作写清了是否写回，而不只是“展示”。
- [ ] 价值可观察；没有基线时已标“待测量”，且写明测量方式、数据来源、校准日期和负责人。
- [ ] “不做什么”至少三条，包含相邻切片。
- [ ] 成功标准能在五天内由真实用户验证。
- [ ] 相关方覆盖审批、操作、需求确认与数据权限。
