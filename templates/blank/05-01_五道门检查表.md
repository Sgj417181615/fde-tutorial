# A05-01 五道门检查表

> 产物路径：`05_五天验证/05-01_五道门检查表.md` ｜ 所属阶段：05_五天验证 ｜ 阶段门：G5

## 用途

在五天验证开始前和结束时，用五道门判断“能不能开始”和“能不能演示”。五道门分别是：窄决策、三方人马、真实数据权限、可演示底座、每日展示。

## 何时用

- D1 开始前做一次预检，缺门先补；
- 每天结束时快速回看是否仍满足；
- D5 阶段门前做最终检查；
- 任何一道门亮红灯时，决定缩小范围或延期。

## 填写说明

1. 五道门固定，不临时增删或合并；每道门至少一行检查项。
2. “证据”写可核查的文件、截图、现场记录或授权书，不写“已确认”。
3. “结论”只填“通过”“有条件”或“不通过”。
4. 有条件的门必须写清补足动作、负责人和截止日期。
5. 检查人不能只由自己签字；涉及数据权限的门要有业务方或信息科确认。
6. 本表结论要与阶段门记录一致，不能一份说通过、另一份说待定。

## 字段

| 门 | 检查项 | 证据 | 结论 | 负责人 | 日期 |
|---|---|---|---|---|---|
| 1 窄决策 | 只做一个最终决策，决策可在一屏内完成 |  |  |  |  |
| 2 三方人马 | 业务、数据、应用三方都有人且能到场 |  |  |  |  |
| 3 真实数据权限 | 有书面授权、脱敏方案与可用的真实数据 |  |  |  |  |
| 4 可演示底座 | 能装载快照、能写回、能在现场操作 |  |  |  |  |
| 5 每日展示 | 每天固定时点向业务方展示增量 |  |  |  |  |

## 质量门自检（G5）

- [ ] 五道门逐项填写，没有合并、跳门或临时加门。
- [ ] 每个结论都有证据，不是口头确认。
- [ ] 结论只使用“通过”“有条件”“不通过”，没有模糊表述。
- [ ] 有条件项写清补足动作与负责人。
- [ ] 检查人不是自己给自己签字。
- [ ] 五道门结论与阶段门记录一致。
