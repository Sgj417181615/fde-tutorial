这是模板的阅读视图，源文件是 README.md。 下载 / 编辑 Markdown · 返回模板库

本目录是教程配套的可复制产物模板。空白模板用于填写，黄金样例用于对照；两者按 artifact 一一配对。

怎么用

  1. 别一次建全 42 份。 先按首页的路线选一档：现场包 7 份、最小档案 12 份、完整档案 42 份。
  2. 从 blank/ 复制一份到自己的 FDE项目档案/，文件名保持不变（<阶段号>-<序号>_<名称>.md），只改内容。
  3. 先看对应的 golden/ 样例，理解每一栏写到什么程度算合格；不要照抄案例事实。
  4. 填写后按模板最后一节的质量门自检；过不了门就不要把产物带到下一阶段。

不想逐份复制，可以整包下载：空白模板、黄金样例、7/12/42 三档档案和 Day1 现场日套装，都在教程首页的资源下载。

配对与维护

  • 空白模板命名：<阶段号>-<序号>_<名称>.md（如 02-04_证据台账.md，不带 A 前缀）；黄金样例命名：<阶段号>-<序号>_<名称>_排班案例.md。
  • 字段以 _canon/artifacts.toml 的 fields 为准；模板与 registry 不一致时，构建检查会报错。
  • 新增或改名 artifact 后，必须同步更新 _canon/artifacts.toml、_canon/templates.toml 与本页。
  • 黄金样例只使用 _canon/case-bible.md 的事实，数字标【示例】；没有的事实写“待定”，不要编。
  • 模板里的质量门自检是对应阶段门的自检版，不替代 _canon/gates.toml 的正式定义。
