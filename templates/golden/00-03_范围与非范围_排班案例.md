# A00-03 范围与非范围（排班案例）

> 【示例】匿名化案例，数字均为示例；人名与机构均为化名。

## 用途 / 何时用

在项目章程阶段、访谈和切片之前使用。本份把本轮验证锁定在“病理科月度外部人员额度分配”这一个决策上，写清做到哪里、明确不做什么、什么条件下需要改范围，避免把相邻的个人排班问题一起塞进来。

**范围口径**：数据月份为 2026-09，快照日期 2026-09-30；只保留妇科病理、乳腺病理、消化病理三个亚专科和王芳、李强、周敏、陈卓四个人。日期与快照均为【示例】。

## 字段

### 包含

| 维度 | 本轮包含 | 说明与来源 |
|---|---|---|
| 流程 | 月度外部人员额度分配：收额度、收需求、核对可用天数、识别冲突、组长确认、主任审批、写回 | CB-01、CB-03、CB-06 |
| 决策 | DC-1 各亚专科本月额度怎么分；DC-2 某个人分到哪个亚专科 | 两个决策合并为一次“额度分配方案”确认，CB-03 |
| 角色 | 陈静主操作；赵岚等组长提需求并确认；周主任审批；孙老师提供额度口径；刘工管数据与权限 | CB-00、CB-04 |
| 数据粒度 | 月 × 亚专科 × 人员 × 人天；另含人员可用天数与资质 | CB-00、CB-05 |
| 时间范围 | 一个月（2026-09）；从拿到额度到方案可审批的完整一轮 | 快照 2026-09-30【示例】 |
| 界面范围 | 额度全景、人员池、冲突面板、组长确认视图、主任审批视图 | CB-07、CB-18 |
| 输出 | 一份可重新打开的分配记录；额度已用与剩余同步更新 | CB-06、CB-09 |
| 验证范围 | C1 超排 1 天、C2 缺口 2 人天在界面上被识别，至少解决一个 | CB-00、CB-09 |

### 不包含

| 不包含项 | 相邻问题 | 为什么先不做 | 何时再看 |
|---|---|---|---|
| S2 个人排班与换班 | 把已分配的人排到具体日期与班型 | S2 依赖 S1 的分配结果，先做会被上游数据卡住 | S1 写回稳定后，作为下一轮切片，CB-18 |
| S3 住院总轮转 | 住院总医师的轮转与替班 | 证据强度低、决策链未摸清，与本月额度分配不是同一决策 | 暂缓，待单独调研，CB-02 |
| S4 报表与统计 | 自动生成月度工时与额度报表 | 没有决策，只有查看；不符合“决策先于数据” | 不做，CB-02 |
| 自动优化算法 | 用求解器自动算出最优分配 | 本轮先做规则校验与冲突提示，避免数学最优但排不出班 | 规则稳定后再评估，CB-09 |
| 工资与绩效核算 | 把分配结果接到薪酬计算 | 涉及绩效口径与审计，超出 S1 决策边界 | 明确不做，CB-04 |
| 与院内系统实时双向同步 | 分配结果自动回写院内系统 | 权限与接口未确认，先用快照加手工写回，保证 Demo 可完成 | D1 前由刘工确认写回方式，CB-09、CB-11 |
| 移动端 | 手机端查看与审批 | 不增加本轮验证面，现有桌面界面足够走通决策 | 不做，CB-09 |
| 外部人员资质认定 | 谁有权认定某人可上哪个亚专科 | 认定口径未定，本轮先复用组长认定结果并标为假设 | 访谈赵岚后确认，CB-11 |

> 以上“不包含”已逐条与周主任、陈静确认；其中 S2 由周主任明确要求“先把分配做稳”。确认记录见 2026-10-09 范围确认会纪要【示例】。

### 边界条件

| 边界条件 | 可检查的判据 | 当前状态 |
|---|---|---|
| 真实数据可用 | 能拿到 2026-09 的额度表、需求记录、排班本与人员资质，且可脱敏 | 已准备快照，CB-10 |
| 用户本人在岗 | 陈静在 D1–D5 能到场操作，不由 FDE 代点 | 已确认，CB-10 |
| 书面授权已签 | 周主任在进场前签署数据授权，范围见 A00-04 | 2026-10-09 书面确认【示例】 |
| 只读账号可用 | 刘工在 D1 前开通院内系统只读账号或提供字段子集导出 | D1 前确认，CB-11 |
| 三个亚专科口径一致 | 需求、额度、分配都按“人天”计，不混用“班次” | 访谈孙老师确认 |
| 审批人能到场 | 周主任或授权审批人在 Demo 当天可审批 | 待确认，CB-10 |
| 写回边界可接受 | 院内系统不能写时，写回本地对象并在演示中明确说明 | 有条件通过，CB-16 |

### 变更规则

| 提出人 | 批准人 | 触发条件 | 记录位置 | 处理方式 |
|---|---|---|---|---|
| 陈静或赵岚 | 周主任 | 发现新的额度规则或例外，影响本月分配 | A00-01 版本记录、A00-03 变更行 | 先记为待确认，不直接扩大范围 |
| FDE | 周主任 | 要新增亚专科、人员或数据类别 | A00-03、A00-04 | 重新评估授权与工时，必要时缩回三个亚专科 |
| 周主任 | 周主任 | 要求把 S2 个人排班并入本轮 | A00-01、本文件 | 默认拒绝；另开一轮切片，CB-18 |
| 刘工 | 周主任 | 院内系统不能写回，需改为本地对象 | A00-03、Demo 脚本 | 缩小写回范围，演示中明确边界 |
| 陈静 | FDE 与周主任 | 关键数据缺失，无法完成一轮分配 | A00-03、A00-05 | 缩小数据范围或延长一天，需书面确认 |

**版本同步**：范围每次变更后，同步更新 A00-01 的版本号与日期，并在下一次每日展示时向陈静口头复述变更点。【示例】
