无前置，从本页开始。

最容易混的五组

相邻术语 一句话区分
MVP / MVD MVP 要能持续使用；MVD 只服务一次演示。
阶段门 / 质量门 阶段门是 G0–G6，管阶段推进；质量门管单份或单页产物过关。
阶段门 / 五道门 阶段门按 00–06 阶段推进；五道门是进五天验证前的一次性准备检查（A05-01）。
访谈证据状态 / 来源权威性 前者答“验证到哪”，后者答“凭什么信”。
生命周期图 / 状态机 / 泳道图 前两者看对象状态，泳道图看角色步骤。

本页术语

FDE Forward Deployed Engineer

扎在客户现场、用工程手段解决业务问题，并对业务结果负责的角色。

首次解释

Use Case（用例） Use Case

由专职团队在限定时间内、为一组明确用户交付新能力的一次努力；它不是“接一个系统”或“上一个算法”。

首次解释

Thin Slice（最薄切片） Thin Slice

一条最短的端到端路径：用真实数据，让真实用户完成一次真实决策，并留下可观察的结果。
